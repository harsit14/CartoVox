Privacy

One page, because there is not much to say.

This website

  • No CartoVox cookies. CartoVox's own pages and scripts set no cookies. The Discover page includes a third-party Discord widget, described below.
  • No analytics. No page-view counter, no tag manager, no pixel, no session recorder, no A/B testing.
  • Self-hosted site assets. Our fonts, scripts, stylesheets and images are served from this domain. The Discover page's live Discord widget connects to Discord when it loads.
  • The Delta service shares this domain. The addresses under /v1/ answered the Delta test builds of CartoVox, not your browser: no page on this site calls them, so reading the site sends nothing to them. CartoVox 1.0 does not use them.
  • No account, no form. There is nothing here to sign up for and nowhere to type your email address, so none is collected.
  • Server logs. The site is static and served by Cloudflare, which sees the ordinary request information any web server sees — your IP address, the page requested, your browser's user-agent string — and uses it to serve and protect the site. That is Cloudflare's processing, not ours, and no one here builds a profile from it or joins it to anything else.

The Discord widget

The Discover page's community section embeds a live server widget hosted by Discord. When it loads, your browser connects directly to Discord, which receives your IP address and browser request information. The widget loads lazily as you approach that section. Its content, cookies and storage are controlled by Discord and your browser's settings; see Discord's privacy policy. The embed sends no page referrer. A separate Join Discord link is available if the widget cannot load.

Download and Discord links

The download buttons fetch the installers from GitHub, where CartoVox releases are published, and Join Discord opens Discord. Both are different companies with their own terms and their own data practices, and receive the ordinary request information described above. Discord links open in a new tab so it is obvious you have left; the Discord invite link carries an invite code, and your browser may send this site's origin as a referrer. What happens once you are on the server is between you and Discord.

The application (CartoVox 1.0)

  • CartoVox never sends anything about you. It only checks for new versions, and you can turn that off. There is no account, no access code, no usage report and no check-in, and it works offline.
  • Your work is stored on your computer. Worlds, maps, lore, names, campaigns, manuscripts, file names and anything you type are files on your own disk. CartoVox does not upload them to the project owner or a cloud account.
  • The update check. When it opens, at most once a day, the installed app asks the public GitHub Releases address where CartoVox is published whether there is a new version. The request carries no user or device identifier, no cookies and nothing about your work; GitHub receives the ordinary network information needed to answer it. Turn automatic checks off, or choose when to download or install an update, in Settings › Updates & support. An update is used only after CartoVox has checked it against our own signature. See section 6 of the licence.
  • Optional tabletop sharing. Choosing Invite players and then Start inviting at the GM desk shares that table's player view with the devices that join, on your own network, or through a VPN or your own web server if you set one up. It includes the player map with fog applied and what you allow players to do, such as rolling dice, pinning notes and moving their own token. GM notes, private rolls and unrevealed tokens stay out of that view. Nothing is shared until you start the invitation, and you can remove a player or stop at any time. How invitations work.
  • Your licence signature stays with you. The name you sign the licence with at first launch is kept on your computer and is not sent anywhere.
  • Diagnostics are yours to send. A diagnostics bundle is assembled locally from build and system information plus redacted logs, and is never uploaded on its own. You choose what to share with support. Read it before you share it.
  • What you make is yours. The licence claims no ownership of your worlds or your writing, and you may publish and sell them. See the licence, sections 6 and 7.

Older Delta builds

The invite-only Delta test builds before 1.0 (up to Delta V16.1, 0.9.18) worked differently, and a Delta build still installed on a computer still does. Unlocking one sent the Delta service a one-way digest of the access code (never the code itself) and a random installation identifier. Taking part in Delta included a usage report, tied to the access code and installation identifier and sent in the background:

  • sessions — when the app started and stopped, how long it was open, its version, the operating system and its version, processor architecture and cores, installed memory, window size, screen size and pixel density, and the name the system gives its graphics processor;
  • feature use — which tabs, tools, buttons, settings menus and exports were used and how often, by the app's own names for them, and the kind of work started (a generation or a rebuild, with its preset);
  • errors — error messages and stack traces from CartoVox's own code, with the home folder, user name and every file path removed;
  • performance — how long generations, rebuilds and renders took, how they ended, and peak memory.

The report never contained worlds, maps, lore, manuscripts, file names or anything typed. It was used only to find defects and improve CartoVox before release, is stored in a Cloudflare D1 database run by the project owner, is kept until 90 days after the Delta programme ends, and is not sold or shared. You can ask on the Discord server to see or delete the report linked to your code. Installing CartoVox 1.0 ends it: 1.0 sends none of this.

If this changes

If this site gains analytics, a form or another third-party embed, this page will say so before it ships, and any affected claims on the site will change with it. Questions go to the Discord server.
