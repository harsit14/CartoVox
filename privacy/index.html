Privacy

One page, because there is not much to say.

This website

  • No cookies. This site sets none, of any kind, including for preferences. There is nothing to consent to, which is why you were not asked.
  • No analytics. No page-view counter, no tag manager, no pixel, no session recorder, no A/B testing.
  • No third-party requests. Every font, script, stylesheet and image is served from this domain. Nothing on a page you load reaches another company. You can confirm it: open your browser's network panel and read the list.
  • The Delta service shares this domain. The addresses under /v1/ answer the CartoVox application, not your browser: no page on this site calls them, so reading the site sends nothing to them.
  • No account, no form. There is nothing here to sign up for and nowhere to type your email address, so none is collected.
  • Server logs. The site is static and served by Cloudflare Pages, which sees the ordinary request information any web server sees — your IP address, the page requested, your browser's user-agent string — and uses it to serve and protect the site. That is Cloudflare's processing, not ours, and no one here builds a profile from it or joins it to anything else.

The one link that leaves

Request an invite opens Discord, which is a different company with its own terms and its own data practices. We open it in a new tab so it is obvious you have left. Nothing about you is passed along with that click — the link carries an invite code and nothing else. What happens once you are on the server is between you and Discord.

The application (Delta builds)

  • Your work stays on your computer. Worlds, maps, lore, names, campaigns and manuscripts are files on your own disk, and CartoVox never sends them anywhere. There is no account.
  • Unlocking registers your computer once. Delta is invite-only. The first time you unlock a Delta build, it sends the Delta service a one-way digest of your access code (never the code itself), a random identifier made for that installation, and the facts listed under sessions below. The service answers whether the code is valid and whether it has been withdrawn. A code can unlock up to three computers.
  • The usage report. Taking part in Delta includes a usage report, tied to your access code and installation identifier, sent in the background:
    • sessions — when the app starts and stops, how long it was open, its version, your operating system and its version, processor architecture and cores, installed memory, and window size;
    • feature use — which tabs, tools, buttons, settings menus and exports you use and how often, by the app's own names for them, and the kind of work you start (a generation or a rebuild, with its preset);
    • errors — error messages and stack traces from CartoVox's own code, with your home folder, your user name and every file path removed;
    • performance — how long generations, rebuilds and renders take, how they ended, and peak memory.
    It never contains your worlds, maps, lore, manuscripts, file names or anything you type. While you are offline it waits on your computer; a Delta build that has not reached the service for 21 days asks you to connect before it opens.
  • Why, where and how long. The report is used only to find defects, see which parts of CartoVox are used, and improve it before release. It is stored in a Cloudflare D1 database run by the project owner, kept until 90 days after the Delta programme ends, and not sold or shared. You can ask on the Discord server to see or delete the report linked to your code.
  • Nothing else leaves. There is no update check: CartoVox never asks whether a newer version exists. Apart from the usage report, the only address it opens is the local dashboard it starts itself. New builds are announced on the Discord server, and installing one is your decision.
  • Diagnostics are yours to send. A diagnostics bundle is assembled locally from build and system information plus redacted logs, and is never uploaded on its own. Read it before you share it.
  • What you make is yours. The licence claims no ownership of your worlds or your writing, and you may publish and sell them. See the licence, sections 6 and 7.

If this changes

If this site ever gains analytics, a form or a third-party embed, this page will say so before it ships, and the claim on the front page will change with it. Questions go to the Discord server.
