CartoVox 0.7.2

Reliable setup guidance and clearer candidate actions

The application was called Atlas Studio until version 0.8.2. Builds are shared with invited testers on the Discord server; these notes are also readable offline inside the app.

Browse releases
All release notes

CartoVox 0.7.2 is a small interface-focused follow-up to 0.7.1. It makes the optional Create setup guide reliable in the desktop app and gives the action that commits a candidate world the visual importance its cost deserves. World generation, saved projects and simulation results are unchanged.

Setup guide opens reliably

  • The Setup guide button now keeps both of the interface's hiding mechanisms in sync, preventing a timing-dependent state where the button reported that the guide was expanded while the desktop app still kept it invisible.
  • One click now opens the actual five-step guide. Authors no longer have to discover and click a second Show guide control after summoning it.
  • Closing and reopening the guide consistently restores the full setup sequence, while the guide's own control can still collapse it when preferred.

Candidate actions are easier to understand

  • Preview, Compare and More now share one compact row on every candidate card.
  • Create Quick world, Create full-resolution world or Generate publication atlas occupies a full-width second row according to the active generation settings.
  • The creation action now uses the same gold primary treatment as Preview, making it clear that this is the consequential action that commits the selected candidate.
  • The two-row hierarchy remains intact at compact card widths.

Compatibility and distribution

  • Existing projects remain readable and are not changed by this update.
  • This release changes interface behaviour only; it does not re-simulate worlds, redraw maps or alter authored canon.
  • CartoVox remains local and limited to invited testers with an offline beta key. Worlds, maps, settings, reports, textures and author data remain on the tester's machine.
