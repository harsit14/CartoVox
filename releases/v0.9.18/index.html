CartoVox Delta V16.1

Delta V16 for Windows with one fix: on some computers every launch stopped responding and had to be closed. A launch that freezes or closes now leaves a record in the logs folder, and CartoVox can open without the graphics processor. Worlds are unchanged, so nothing needs rebuilding.

The application was called Atlas Studio until version 0.8.2. Builds are shared with invited testers on the Discord server; these notes are also readable offline inside the app.

Delta V16.1 is Delta V16 for Windows with one fix: on some computers every launch stopped responding and had to be closed. Worlds are unchanged, so a world built or rebuilt in Delta V16 needs no rebuild.

Settings and the app

  • On Windows, CartoVox no longer stops responding as it opens. Delta V16 could freeze while the Library or the last world loaded, on some computers at every launch, and had to be closed from the Task Manager. Opening CartoVox a second time while it is open no longer risks the same freeze.
  • On Windows, a CartoVox that freezes or closes while it opens now leaves a record of how far it got, and of any crash, in its logs folder, ready to send on Discord.
  • If the window did not finish opening last time, CartoVox asks whether to open without the graphics processor; the turning globe is not drawn then. Start CartoVox with --safe-graphics to choose it yourself, and with --normal-graphics to go back.
  • Create diagnostics, in Settings, now includes the local service's log and any crash record, not just the window's log.
