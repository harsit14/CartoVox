CartoVox 0.7.6

Reachable and selectable Create setup

The application was called Atlas Studio until version 0.8.2. Builds are shared with invited testers on the Discord server; these notes are also readable offline inside the app.

Browse releases
All release notes

CartoVox 0.7.6 fixes the remaining interaction problems in the optional Create setup guide. Finite text choices are now real dropdowns, expanded setup controls remain reachable without closing other sections, and the guide's starting-path action opens the route chooser as promised.

Setup choices are selectable

  • Every exposed setting with a fixed vocabulary now publishes its valid choices through the shared configuration schema.
  • The optional setup guide and Advanced Settings both render those values as dropdowns instead of unrestricted text boxes.
  • This covers terrain image interpretation, magic source and cost, naming-family rules, apostrophe policy, atlas label density, lake display detail and map palette.
  • Friendly labels are displayed while the stable internal values remain unchanged for saved recipes and reproducible builds.

Expanded Create controls remain reachable

  • The Create page gains an outer escape scroll when the optional guide or generation-options panel makes the setup surface taller than the window.
  • The brief and candidate columns keep their ordinary local scrolling during normal work.
  • The generation-options panel has a bounded height and its own scroll fallback, so its last controls are available on shorter displays.

Creation paths behave consistently

  • The route summary now carries a stable Creation path caption, making clear that Generate, Import, Deep Time and manual setup are saved choices rather than different application builds.
  • Choose how to begin in the setup guide now opens the same three-path chooser as the route bar's Change button.
  • Both entry points share one state transition, preventing one control from becoming inert while the other continues to work.

Compatibility and distribution

  • Existing projects, recipes and generated worlds remain readable and are not re-simulated by this update.
  • CartoVox remains local and limited to invited testers with an offline beta key. Worlds, maps, settings, reports, textures and author data remain on the tester's machine.
