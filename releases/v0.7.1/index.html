CartoVox 0.7.1

Deeper world editing, stronger imports, and safer iteration

The application was called Atlas Studio until version 0.8.2. Builds are shared with invited testers on the Discord server; these notes are also readable offline inside the app.

Browse releases
All release notes

CartoVox 0.7.1 is a focused follow-up to 0.7.0. It expands terrain and feature editing into a practical world-revision workflow, makes external maps easier to interpret before spending simulation time, adds imperial display units, and recovers more safely from interrupted generation. Existing projects remain readable and are never silently rebuilt.

Sculpt the world with clearer intent

  • Sculpt now previews the likely terrain result directly on the map, with clearer tools, footprints, strength and shape controls before anything is applied.
  • Island building supports finer shapes instead of a single blunt circular uplift. Coast, peak, ridge, plateau, basin, strait, river-valley, flatten, smooth and detail tools provide complementary ways to build and refine terrain.
  • Select feature reads the editable terrain, water, ecology, settlement, route, realm and magical-region features beneath a point. Clicking the selected feature again now reliably deselects it, including while an earlier lookup is still completing.
  • Applied changes create restorable revisions. The interface explains which downstream systems will be rebuilt before re-simulation.

Remove and reshape generated features

  • Land, islands, lakes, rivers, biome regions and mountain terrain can be removed or reshaped through feature-aware operations rather than imprecise map guessing.
  • Settlements can be removed or relocated while preserving the distinction between authored intent and generated downstream consequences.
  • Routes and realm boundaries can be reshaped with feature-specific controls.
  • Magical regions can be selected and edited alongside physical and political features.
  • Operations that cannot honestly preserve a generated feature explain the constraint and stage the closest supported world change instead of pretending to edit disconnected pixels.

Deep Time is easier to author

  • The initial subcontinent drawing workspace is larger and opens directly when its custom-drawing card is chosen.
  • Authors can change brush width, draw a closed outline and fill the enclosed continent with one action.
  • The drawing workspace has explicit back and close actions, so opening it never traps the author in an unwanted step.
  • Clearer guidance and previews make early continental composition easier to understand before committing it to the simulation.

Better external-map import

  • The import workshop now distinguishes heightfields, land-and-water masks and coloured illustrated maps more carefully.
  • A preview stage shows the interpreted land mask and coastline before generation begins, with controls for inversion, cleanup and interpretation.
  • Colour-map handling is more tolerant of labels, borders, decorative water, shaded land and other cartographic detail that previously confused simple colour thresholds.
  • Guidance states what geography can be preserved and which terrain, climate, rivers, biomes, settlements and lore Atlas must regenerate.

Safer generation and familiar units

  • Metric and imperial display units are available across world summaries, map inspection and relevant measurements without changing the saved simulation.
  • Interrupted or force-closed generation records are detected and can be recovered or removed instead of leaving an undeletable project card.
  • Temporary seed previews are kept separate from committed worlds, and failed preview imagery no longer requires deleting all application data to recover the workspace.
  • Generation cleanup preserves completed world data and avoids treating an abandoned in-progress record as a valid finished project.

Compatibility and distribution

  • Existing 0.7.0 and older projects remain readable. Feature edits and full re-simulation are deliberate actions that create revisions; opening a world does not rewrite it.
  • Terrain edits can change downstream climate, rivers, biomes, settlements, routes, names, lore and maps. Atlas states that scope before applying them.
  • External-map interpretation is still an inference from pixels. Always inspect the preview and correct the land mask before committing a long simulation.
  • CartoVox remains local and limited to invited testers with an offline beta key. Worlds, maps, settings, reports, textures and author data remain on the tester's machine.
