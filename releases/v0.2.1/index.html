CartoVox 0.2.1

current tester dashboard patch

The application was called Atlas Studio until version 0.8.2. Builds are shared with invited testers on the Discord server; these notes are also readable offline inside the app.

All release notes

This is the current invited technical-alpha build. It keeps the complete v0.2 worldbuilding upgrade and fixes the crowded dashboard header reported after release.

Dashboard and responsive navigation

  • World shape, seed, and detailed generation settings now live in a dedicated Generation setup strip at the top of Create instead of competing with every workspace tab in the global header.
  • The global header is reserved for CartoVox navigation plus Preview and Generate, preventing controls from merging or covering one another on desktop and laptop windows.
  • The section navigation can scroll safely when space is unusually constrained instead of overlapping adjacent actions.
  • At phone width, generation setup becomes a compact two-row control so a complete ten-digit seed remains readable and the generation-options menu stays reachable.
  • The recipe selector, seed input, Quick mode, atlas selection, plate finish, village density, and sheet-selection controls retain their existing behavior and saved values.

Verification

  • Responsive browser checks passed at 2048, 1440, 1024, 760, and 390 pixels with no element collisions, horizontal page overflow, or browser-console errors.
  • The complete automated suite passes, including a regression that keeps generation controls inside Create and outside the global header.
  • The tagged workflow validates v0.2.1 against application and installer metadata, then builds and verifies Apple Silicon macOS, Intel macOS, Windows, and Linux x64 installers with SHA-256 checksums.

Invited alpha access

CartoVox remains limited to invited testers with an offline beta key. Existing worlds and keys remain compatible; installing this patch does not move, upload, or replace locally generated worlds.

Full generation is intentionally demanding and may take roughly 20–25 minutes on a current high-end Mac and 50–55 minutes on a current high-end Windows machine, depending on settings and selected atlas plates. Use Preview, Quick, Draft atlas finish, or selective plates while exploring.
