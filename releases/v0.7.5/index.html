CartoVox 0.7.5

Reliable installed setup guide and detailed rivers

The application was called Atlas Studio until version 0.8.2. Builds are shared with invited testers on the Discord server; these notes are also readable offline inside the app.

Browse releases
All release notes

CartoVox 0.7.5 corrects two release-blocking differences between the development dashboard and installed applications. High-detail physical maps now retain their river networks, and packaged apps now include the analysis inputs required by the Create setup guide and Settings help.

Installed guidance works like the development dashboard

  • macOS, Windows and Linux bundles now include the readable Atlas modules used to explain which simulation systems each setting affects.
  • The build verifies those packaged analysis inputs byte-for-byte before creating an installer.
  • The packaged-app smoke test exercises the authenticated setup-guide endpoint, so an installer cannot pass merely because its static HTML loads.
  • Setup-guide loading, failure and retry states remain visible instead of making the button appear unresponsive.

Rivers survive high-detail redraws

  • Physical relief and biome maps restore the persisted river network at 2x, 3x and 4x map detail.
  • River coordinates, hierarchy and discharge information remain aligned with the enlarged terrain drawing.
  • Existing riverless high-detail caches are invalidated automatically and rebuilt when opened.
  • Hydrology-graph changes invalidate affected relief and biome drawings instead of leaving stale cached results.

Additional reliability

  • Map inspection accepts the current packaged response format and is protected by a browser-to-desktop schema regression check.
  • Existing worlds and simulation results remain unchanged; only derived display drawings are rebuilt as needed.

Compatibility and distribution

  • Existing projects remain readable and are not re-simulated by this update.
  • CartoVox remains local and limited to invited testers with an offline beta key. Worlds, maps, settings, reports, textures and author data remain on the tester's machine.
