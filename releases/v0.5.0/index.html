CartoVox 0.5.0

guided worldbuilding, climate forensics, author-directed geology, and production rendering

The application was called Atlas Studio until version 0.8.2. Builds are shared with invited testers on the Discord server; these notes are also readable offline inside the app.

All release notes

This is the current invited technical-alpha build. It turns the simulation systems added through 0.4 into workflows an author can discover and control: choose how to begin, state what the world is for, inspect why the climate behaves as it does, constrain selected nations and tectonic causes, experiment with erosion, and export large layered artwork without confusing drawing resolution with simulation resolution. Existing worlds remain readable; tools that need saved scientific fields explain when an older project must be deliberately re-simulated.

A clearer route into Atlas

  • The Create workspace now begins with three genuinely different paths: generate a new world, import an existing map, or build through geological deep time.
  • A second purpose choice tunes the route for campaigning, climate study, an illustrated atlas, a base for external artwork, or writing and worldbuilding. These choices set ordinary visible options rather than hiding a new preset system.
  • The candidate search now separates planetary conditions from continental geography, so changing the kind of planet no longer has to masquerade as changing its landmass topology.

Climate Lab and explainable weather

  • Selecting a map cell can now explain its temperature and rainfall departures using latitude, elevation, continentality, upwind terrain, moisture supply, and the saved circulation fields.
  • Climate Lab exposes seasonal temperature, pressure, wind, and rainfall frames; moisture-path inspection; located plausibility checks; and a local review bundle containing the seed, resolved configuration, model response, and findings.
  • A bounded what-if comparison estimates how selected climate controls would change the saved world and clearly labels the result as an approximation rather than a full physical re-simulation.
  • Seasonal fields are stored compactly so an author can scrub the year without doubling the scientific archive.

Nations and tectonics before generation

  • Nation Brief lets authors name realms and capitals, request homeland traits, biome preferences, resources, trade goods, and cultures, and check those requests against measured terrain before generation.
  • Accepted homeland anchors enter the normal civilisation pipeline as founding hearths; locked names flow through the stable naming registry so maps, reports, and lore agree.
  • Tectonic Director now covers craton nuclei, plate seeds, requested convergent/divergent/transform margins, drift and speed, locks, and mantle hotspots.
  • Preflight reports contradictory or impossible requests before a long build. A finished-world conflict report then measures which intentions were satisfied, compromised, or impossible instead of merely repeating the input.

Import Workshop and Erosion Lab

  • Existing-map import now has a preview workshop between choosing an image and committing a world. It detects likely heightfield versus land/water art, supports inversion and cleanup, previews the resulting coast, and states which requested features can be preserved or must be rebuilt.
  • Erosion Lab runs the same stream-power, hillslope-diffusion, and floodplain-deposition kernel used by generation on a non-destructive coarse bench.
  • The lab compares relief and drainage before and after, visualises what moved, reports mass balance and scale limitations, and changes the world only after an explicit accept-and-re-simulate action.
  • Separate fluvial-incision and hillslope-diffusion controls default to the historical behaviour, preserving untouched configurations.

Render Studio for artists and GIS workflows

  • Render Studio produces 1K, 2K, 4K, 8K, or tiled 16K output as documented transparent PNG layers with world files, a compositing manifest, and a flattened preview.
  • Authors can choose full-colour, monochrome, or coastline-only bases; include biomes, relief, lakes, rivers, coastlines, borders, graticules, and labels; and use local textures from the Atlas data directory.
  • Continuous fields are interpolated, categorical fields remain categorical, and deterministic decorative detail is explicitly marked as invented.
  • Every bundle records both output-pixel size and underlying simulation-cell size. Render Studio never claims that a larger drawing is a higher-resolution physical simulation.
  • Rebuildable Render Studio output is excluded from portable project backups so a single 16K export does not silently bloat the authoritative world archive.

Planet classification and honest capability boundaries

  • A versioned planet-class foundation classifies supported terrestrial regimes separately from geography and carries stable machine IDs, familiar names, physical ranges, confidence, references, and capability states.
  • The Create workspace and world dossier now state which stages are supported, optional, or inapplicable and list important standing limits such as simplified atmospheric physics, water-only hydrology, and the current Earth/Köppen biome vocabulary.
  • Scientific exports include the derived classification and limitations, so downstream analysis retains the context in which a world was generated.

Faster, safer alpha feedback

  • A tester can report the current map or selected cell, describe expected versus observed behaviour, complete a short task-specific checklist, and preview exactly what will be collected.
  • Reports are written beside the world and are never uploaded automatically. Generated place names and annotated screenshots remain excluded unless the tester explicitly includes them.
  • The new shared compass-globe identity now appears in the web shell, desktop applications, installers, and platform icon assets.
  • The Regional Lens panel scrolls independently instead of letting wheel events zoom the map underneath it.

Compatibility and verification

  • Project configuration advances to schema version 8 for the separate erosion controls. Missing values migrate to neutral defaults; older worlds are not silently re-simulated.
  • Existing projects, revisions, backups, campaigns, Chronicles, lore, imported terrain, extensions, and author decisions remain readable. New climate frames, nation reconciliation, tectonic audits, and render products appear only when their required saved inputs exist or after a deliberate re-simulation.
  • This candidate passes 997 automated tests, Python compilation, JavaScript syntax checks, release-version validation, and a browser smoke test of the guided Create workflow with no console errors.
  • The tagged build workflow produces and verifies Apple Silicon macOS, Intel macOS, Windows, and Debian/Ubuntu Linux installers. The separate portable-Linux workflow builds against glibc 2.28 for Slackware 15.0 and other non-Debian distributions.

CartoVox remains limited to invited testers with an offline beta key. Verification uses no account, telemetry, hardware fingerprint, activation server, or network connection. Generated worlds, settings, reports, textures, and author data remain on the tester's machine.

Full generation is intentionally demanding and may take roughly 20–25 minutes on a current high-end Mac and 50–55 minutes on a current high-end Windows machine, depending on settings and selected atlas plates. Use Preview, candidate search, Quick mode, Draft atlas finish, or selective plates while exploring. Twelve-sample climate, regional work, Erosion Lab acceptance, and large renders require additional time, memory, or disk space.
