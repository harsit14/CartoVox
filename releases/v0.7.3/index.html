CartoVox 0.7.3

Map inspection and setup guide reliability

The application was called Atlas Studio until version 0.8.2. Builds are shared with invited testers on the Discord server; these notes are also readable offline inside the app.

Browse releases
All release notes

CartoVox 0.7.3 is a corrective update for two release-blocking interface problems found before the previous installers were distributed. It restores map inspection against the current desktop response format and makes the Create setup guide resilient when its first request is slow or unsuccessful.

Map inspection works with current worlds

  • Clicking a map location now accepts every cell-inspection response schema supported by the bundled desktop application.
  • The browser and Python response versions are kept in lockstep by a focused regression check, preventing another packaged build from rejecting valid current responses as out of sync.
  • Existing worlds and simulation data are unchanged.

Setup guide remains usable

  • Opening the setup guide now shows its interface immediately while the guide data loads.
  • A failed request presents a clear error and Try again action instead of making the button appear unresponsive.
  • The packaged-app smoke test now exercises the authenticated setup-guide endpoint, catching failures that browser-only testing could miss.

Compatibility and distribution

  • Existing projects remain readable and are not re-simulated by this update.
  • CartoVox remains local and limited to invited testers with an offline beta key. Worlds, maps, settings, reports, textures and author data remain on the tester's machine.
