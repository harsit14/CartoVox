2.1 Components bundled inside the libraries above

Matplotlib, NumPy and Pillow each embed additional third-party material. Their own licence files ship unchanged inside their packages and cover, at least:

  • Matplotlib — AMS and BaKoMa Computer Modern fonts, ColorBrewer colour schemes (Apache-2.0), Qhull, STIX Fonts, Solarized, Yorick/Gist colour maps, and a ResizeObserver polyfill (CC0-1.0). See _internal/matplotlib/LICENSE/. It also ships the DejaVu fonts (Bitstream Vera and Arev font licences; the DejaVu changes are in the public domain), whose text is _internal/matplotlib/mpl-data/fonts/ttf/LICENSE_DEJAVU, and the STIX fonts (SIL OFL 1.1). CartoVox embeds subsets of DejaVu Serif and STIX General in the PDF files it writes; see section 5.2.
  • NumPy — a small number of MIT, Zlib, 0BSD and CC0-1.0 sources, enumerated in _internal/numpy/licenses/.
  • Pillow — its own LICENSE file retains the historical PIL notices.

2.2 Note on OpenCV and FFmpeg

The opencv-python-headless wheels bundle an FFmpeg build for video I/O. Those FFmpeg binaries are distributed under LGPL-2.1-or-later with optional components under GPL. CartoVox uses OpenCV for image analysis only and does not invoke FFmpeg, but the binaries are present in the package. If you redistribute CartoVox, or if you require a build without LGPL/GPL components, replace opencv-python-headless with a build compiled without FFmpeg.

2.4 The application launcher

The installed application is packaged with PyInstaller 6.22.3. The small launcher program it adds (the "bootloader") is licensed under the GNU General Public License version 2 or later with the PyInstaller bootloader exception, which allows it to be distributed with a program under any licence, including a proprietary one, provided the bootloader itself is not modified. 3.1 The licence choice used by CartoVox

CartoVox uses the LGPL-3.0-only option for PySide6 and the Qt-specific portions of Qt WebEngine. These components are separate shared libraries loaded by the Python binding; CartoVox does not statically link, patch or rename them. Chromium material inside Qt WebEngine remains under the licences recorded by Qt in its bundled third-party notices.

The complete LGPL-3.0 and GPL-3.0 texts ship under _internal/third-party-licenses/qt/ from the reviewed, unmodified copies in desktop/legal/qt/. PySide distribution metadata remains under _internal/*.dist-info/, and Qt's third-party licence inventory remains under _internal/PySide6/.

3.2 Replacement and relinking

The installed Debian application stores its replaceable Qt libraries under /opt/cartovox/_internal/PySide6/; the portable build stores the same directory under CartoVox/_internal/PySide6/. A recipient may copy the bundle, replace those LGPL libraries with a compatible modified build, and run the resulting copy for the purpose of debugging those modifications. CartoVox does not use integrity checks or access-key logic to prevent that replacement. Back up the original bundle first because a different ABI may fail to start and modified Qt builds are outside CartoVox support.

Source for the exact PySide6 and Qt release can be obtained from the Qt for Python repository identified in the wheel metadata and from The Qt Company's Qt source archives. EULA section 8.3 controls any conflict: the third-party terms prevail for those components, including the rights to inspect, modify and relink the LGPL-covered libraries. The proprietary EULA continues to govern CartoVox's own code and assets.

The candidate release still requires native verification of both Linux artifacts and the Windows installer. This notice describes the selected source policy; it is not a claim that an unverified installer passed those platform checks.

5.2 Fonts inside the files CartoVox writes

PDF files CartoVox writes (the vector map and the bound atlas) embed subsets of fonts that ship with Matplotlib: DejaVu Serif (Bitstream Vera and Arev font licences) and STIX General (SIL OFL 1.1). Both licences allow the fonts to be embedded in documents that are sold or distributed; the fonts remain under their licences and the documents do not. SVG files CartoVox writes name the fonts they ask for (for example Georgia, then a generic serif) and embed none, so nothing of a system font is copied into them.

9. Maintaining this file

This inventory must be regenerated whenever a dependency is added, removed, or has a version range that resolves differently. The packaged build embeds a CycloneDX software bill of materials at _internal/build-provenance/sbom.cdx.json; that SBOM should carry the same licence identifiers as this file.

See docs/reference/licensing.md for the maintainer checklist and the outstanding items that must be closed before CartoVox is sold.

Contextual lettering libraries and fonts

Offline map captions use the unmodified uharfbuzz and python-bidi libraries. Their distribution metadata and full licence texts ship with the application; HarfBuzz's complete copyright notice and exact version/source references are retained in third-party-licenses/contextual/. The python-bidi source is at <https://github.com/MeirKriheli/python-bidi/tree/v0.6.11>. Its LGPL terms allow use, modification and replacement of that library; they do not replace the CartoVox licence for other code. The LGPL text and incorporated GPL text are both retained in the library's dist-info/licenses directory.

Noto Sans Arabic, Devanagari, Hebrew, Thai and Khmer caption fallbacks are unmodified SIL OFL fonts. web/vendor/fonts/contextual-sources.json records the exact upstream files and hashes; family-specific full OFL texts are kept beside the fonts. These fonts do not replace the interface's existing faces.
